# 상황 안내 시연·검증 시나리오

`시나리오.json`은 `sample_data/regulations/예시_○○시_복무_내규.txt`와 함께 사용하는 가상 자료입니다. 실제 기관 규정이나 법령이 아닙니다. 날짜를 포함한 기대값은 기준일 **2026-11-09**에 고정한 자동 테스트용이며, 현재 날짜로 화면에서 실행하면 상대 날짜가 달라집니다.

1. 설정의 규정 폴더에 위 예시 내규 폴더를 연결하고 색인합니다.
2. 상황 안내에서 JSON의 `입력`을 입력합니다. 절차의 원문·근거, 서식, 할 일을 함께 확인합니다.
3. 출장 종료일을 빼거나 추가해 기한 안내가 어떻게 달라지는지 비교합니다. 정산은 복명서의 실제 제출일을 알아야 하므로 자동으로 날짜를 정하지 않습니다.
4. 근거 없는 회의의 절차는 만들어 내지 않는지, 시간외근무의 시각은 빈칸으로 남는지 확인합니다.

자동 검증: `python -m pytest tests/test_guide.py -q`. 기한 자동 계산은 주말만 고려하므로 공휴일과 실제 기관 규정은 별도 확인해야 합니다.
