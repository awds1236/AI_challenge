# 세션 2 서무비서 점검 및 시연 메모

## 공모 내용과 제품 연결

2026년 공공 AI 대전환 챌린지의 AI 미션 부문은 서무비서를 포함한 세 가지 지정과제 중 하나를 선택합니다. 공모 소개에서 서무비서는 규정·지침을 저장하고 상황에 따라 **절차 확인, 서식 초안, 다음 할 일**을 안내하는 도구로 설명합니다. 제품의 상황 안내 화면은 세 결과와 근거 조문을 함께 보여 주며, 기관 서식 채우기와 할 일 등록을 지원합니다.

- [행정안전부 보도자료 (2026.10.21.)](https://www.mois.go.kr/frt/bbs/type010/commonSelectBoardArticle.do?bbsId=BBSMSTR_000000000008&nttId=130377): AI 미션 지정과제, 11월 11일까지 접수, 11월 25일 결선 발표·시연.
- [2026년 공공 AI 대전환 챌린지 공모 소개](https://gcontest.co.kr/front/m/comp/view/37930): 서무비서 과제 설명과 기관별 신청자 목록 공문 제출 및 참가자 제출물 안내. 2차 소개 자료이므로 제출 양식·마감 시각·최신 변경 사항은 기관 담당부서와 주최 측 원문으로 확인합니다.

공개적으로 확인한 내용만 정리했습니다. 세부 심사 배점이나 제출 형식의 충족 여부를 여기에서 보증하지 않습니다.

## 시연 순서

1. `sample_data/regulations/`의 가상 내규를 규정 저장소에 연결하고 색인합니다. 실제 기관 규정이 아님을 설명합니다.
2. `출장 다녀와서 정산해야 해요`를 입력합니다. 종료일을 알 수 없어 날짜를 만들지 않고, 후속 정산은 실제 복명서 제출일을 확인하도록 안내하는지 보여 줍니다.
3. 실제 종료일을 포함해 다시 입력하고 복명 기한, 제7·8조 근거, 영수증 등 준비 서류를 확인합니다. 주말만 반영한 계산이라는 안내도 확인합니다.
4. 서식 초안과 기관 서식 채우기, 필요한 할 일 선택·등록을 보여 줍니다.
5. 구매, 시간외근무, 관련 규정 없는 회의 등은 `sample_data/상황안내/시나리오.json`과 README를 참고합니다. 상대 날짜 기대값은 기준일이 고정된 자동 테스트용입니다.

## 검증과 남은 확인

- Linux 환경에서 전체 자동 테스트: 201 통과, 3 건너뜀. 이후 추가한 동시 행사·제출일 사례를 포함한 관련 테스트 103개도 통과했습니다. 규정 검색·상황 안내·공문 예시·기관 서식·보고서와 API 흐름을 포함합니다. AI 연동은 가짜 서버를 이용한 테스트를 포함합니다.
- 모의 AI가 없는 숫자나 서류를 추가하거나, 행사일·행사 시각을 제출 기한으로 혼동하는 사례를 확인했습니다. 새로운 검증은 이런 사례를 거르지만 문장 의미의 정확성을 보장하지 않습니다.
- Chromium 브라우저에서 상황 안내, 근거와 종료일 미상 안내, 할 일 등록, 시간외근무 초안 확인.
- Windows 전용 창 수집 및 OCR은 이 환경에서 검증하지 못했습니다. 실제 로컬 AI 모델 파일이 없고 다운로드 요청이 차단되어 실제 모델의 응답 품질·속도 및 개선 전후 차이도 확인하지 못했습니다. 대회용 Windows PC에서 설치·오프라인 실행·실제 모델과 기관 서식·시연 흐름을 확인해야 합니다.
- 공휴일과 기관별 기한 규칙은 자동 반영되지 않습니다. 규정과 AI 출력, 계산된 날짜는 담당자가 확인해야 합니다.
