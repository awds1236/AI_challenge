# 시연영상 촬영 대본 (서무비서 AI · 세션 2 지정과제 ② 서무비서)

## 제출 규격 (공고문 4. 제출물 안내)
- **길이·형식**: 약 5분 이내, **mp4**
- **내용**: 구동안내서의 핵심 흐름을 **실제 화면**으로 시연하고, **음성 또는 자막**으로 설명 (심사위원이 직접 구동할 때 참고 자료로 씀)
- **파일 이름**: `[시연영상]_기관명_팀명(개인은 성명).mp4`
- **제출**: 참가신청서·구동안내서(PDF)와 함께 이메일 `databus@nia.or.kr`, 제목 `[공공 AI 대전환 챌린지 제출]_세션2_기관명_팀명` (마감 **11. 11.(수)**, 도착 기준)

## 촬영 전 준비
1. 해상도 1920×1080, 화면 배율 100~125%, 알림 끄기(방해 금지), 바탕화면 정리. 개인정보가 보이는 창은 닫기.
2. 프로그램을 처음 상태로: `%LOCALAPPDATA%\SeomuAI` 폴더 이름을 잠시 바꿔 두면 새로 설치한 것처럼 시작됩니다(촬영 후 되돌리기).
3. 모델 두 개를 미리 받아 두기: **Gemma 4 E2B**(기본), **Kanana-2 3B**(교체 시연용). 받는 장면은 길어서 촬영 전에 끝내 둡니다.
4. 한 번 미리 실행해 AI 엔진을 메모리에 올려 둡니다(첫 답변이 빨라집니다).
5. 녹화 도구: Windows **캡처 도구(Win+Shift+R, 동영상)** 또는 **Xbox Game Bar(Win+Alt+R)** → mp4로 저장. 자막·자르기는 Windows 기본 **Clipchamp**로 넣으면 됩니다.
6. 기다리는 장면(AI 답변 수십 초)은 편집에서 잘라 내고 자막에 "실제 대기 ○초"를 남기면 정직하고 짧아집니다.
